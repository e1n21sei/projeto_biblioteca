 📚 Projeto Biblioteca

Sistema de gerenciamento de biblioteca desenvolvido em java, durante o curso de Desenvolvimento de Sistemas.

Tecnologias utilizadas:

- Java
- programação orientada à objetos ( POO)
- Github

Funcionalidades:

- Cadastro de usuários. 
- Cadastro de livros. 
- Empréstimo de livros. 
- Devolução de livros. 
- Controle de disponibilidade dos livros.
